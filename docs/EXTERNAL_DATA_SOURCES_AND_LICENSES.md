# External data sources, storage, and upstream terms

## Public CLIP panel

Flickr30k CLIP features are pinned to Hugging Face dataset `lance-format/flickr30k-lance` at commit `c67a4b5fad0afb8e8c79464e3dc536c1009e9a80`.

MSCOCO Captions 2017 CLIP features are pinned to `lance-format/coco-captions-2017-lance` at commit `d9e9db0edccae4b9c3c005b7392569d7f657157c`. The canonical analysis uses the 5,000-row validation split and the 40,670-row pinned public-test artifact recovered for the sealed analysis. Current dataset-card metadata should not silently replace the pinned artifact used in the experiment.

The COCO Lance dataset card declares CC BY 4.0 for the redistributed dataset/annotations while warning that underlying images remain subject to Flickr/COCO terms. The Flickr30k Lance card lists its license as `other` and asks users to review Flickr30k/Flickr terms before redistribution. Because the project needs only feature arrays, the safest public-release policy is to keep pinned acquisition instructions, hashes, and derived outputs in GitHub and rematerialize raw third-party arrays locally unless redistribution permission is clear.

## SUE released Flickr representations

The development record also contains released Flickr30k representation tensors used by strict SUE diagnostics: `encoded1.pt` (31,783 x 768) and `encoded2.pt` (31,783 x 2,048). These are external released representations, not generated by this project, and should be treated according to their upstream terms.

## What belongs in this public repository

All project-generated code, derived tables, small intermediate data, sealed-protocol metadata, hashes, manifests, and deterministic reproduction scripts should be versioned here when they are needed for the course paper. Large third-party tensors should not be republished merely to make the repository look complete. Exact pinned acquisition/materialization instructions plus SHA-256 provenance are the preferred route unless redistribution rights are clear.
